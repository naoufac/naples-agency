# naples.agency

Autonomous systems agency — AI fleets, agent orchestration, production-ready web experiences.

## Quick Start

```bash
# Clone repo
git clone https://github.com/naoufac/naples-agency.git
cd naples-agency

# Serve locally
python3 -m http.server 8000

# Or use any static file server
```

## Stack

- **HTML5** — Semantic markup
- **CSS3** — Modern styling, animations, responsive design
- **JavaScript** — Mobile navigation, smooth scroll, intersection observers
- **GitHub Pages** — Production deployment
